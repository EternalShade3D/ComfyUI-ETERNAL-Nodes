Panorama 360 Viewer Eternal

Inspect a 360° equirectangular panorama directly inside your ComfyUI node. Drag to look around, scroll to zoom with live FOV write-back, and check seams, poles, and horizon tilt without leaving your workflow.

See It In Action

Real 1080p recording inside a live ComfyUI workflow — zero mock-ups. Download on Releases →

Built for Live 360° Inspection

Native ComfyUI previews show a flat 2:1 plate. This node renders the unwrapped equirectangular image on a true sphere right inside your graph.

🌐

Interactive WebGL Sphere + FOV Write-Back

Drag to orbit around your panorama and scroll to zoom between 30° and 140° FOV (default 100°). Every scroll writes the new FOV straight back to the node widget, so the framing you choose saves with the workflow.

Real-Time Canvas Node
⚙️

Gear Settings Panel & Pass-Through Output

The schema widgets are hidden from the body and replaced by a custom control band, quick sliders, fullscreen glass UI, and a floating Gear panel. An image pass-through lets the viewer sit mid-graph instead of ending it.

Mid-Graph Pass-Through

Everything Included in Panorama 360 Viewer Eternal

📦

Works Fully Offline

Three.js r128 ships inside js/vendor/three.min.js as a private module — zero CDN, zero internet, zero global state collision.
🛡️

2D Software Fallback

When WebGL is disabled or unavailable, a 2D software equirectangular projector draws the same view — never blank.
🔄

Smart Auto-Rotation

Toggle Auto drift from −60°/s to +60°/s. Pauses immediately when you grab the sphere and resumes when you release.
↕️

Z-Axis Camera Height

Slide the eye up or down (−99% to +99% of sphere radius) independently from pitch — true translation with a level horizon guide.
☀️

Non-Destructive Exposure

Adjust viewer brightness (0.2–3.0) and background (dark / black / grey / light) without touching wire data.
🎞️

Batch Frame Index

Inspect any image in a multi-frame batch with frame_index while passing the full tensor downstream untouched.

Node Surface & Captures

The real node surface on canvas — demo video is up top in See It In Action.

Top Control Band

Stepper buttons (− / +) and editable FOV box, an Auto spin switch, and quick action buttons for Reset View, Fullscreen, and the Settings panel.

Three Quick Sliders

Zoom (unit toggle ° FOV / %), Spin (−60°/s to +60°/s), and Height (−99% to +99% Z-axis) stay bound to the node so every tweak saves in your workflow JSON.

Live Viewport Chip

Corner readout shows vertical and horizontal FOV (fov 140° (154° wide)). Searchable on canvas via 360, panorama, equirectangular, sphere, or vr.

Canvas Control Band & Quick Sliders

− 105° + FOV stepper, Auto switch, Reset / Fullscreen / Settings buttons, and live Zoom (° FOV or %), Spin, and Height sliders.

Fullscreen Mode with Glass HUD

Pure CSS :fullscreen layout flips the controls to a frosted glass dock at the bottom while the sphere fills the entire screen.

Floating Gear Settings Panel

Top section binds directly to the node's workflow inputs: FOV, Auto-rotate, Background, Start yaw/pitch, Camera height (Z), and Exposure.

Global Defaults & Horizon Guide

Customize min/max FOV bounds, wheel & drag sensitivity, wheel mode (panorama vs canvas zoom), horizon ring guide, and one-click Save view to node.

Documentation & Reference

Exact inputs, outputs, settings, and usage notes for Panorama 360 Viewer Eternal.

🎛️ Node Inputs & Outputs (EternalViewer360)
image (IN / OUT)IMAGE — Equirectangular 360° image (2:1 aspect). Passed through to the image output unchanged.
frame_indexINT (0–4096, default 0) — Selects which frame of an image batch to inspect.
fovINT (30–140, default 100) — Opening vertical field of view in degrees. Wheel & stepper write back live.
auto_rotateFLOAT (−60.0 to 60.0, default 0.0) — Degrees per second drift (0 = off). Pauses while dragging.
backgroundCOMBO (dark / black / grey / light) — Scene backdrop visible around poles.
exposureFLOAT (0.2–3.0, default 1.0) — Viewer brightness only; never modifies the image tensor on the wire.
start_yawFLOAT (0–360, default 180) — Horizontal starting angle (0/360 = image edge, 180 = center).
start_pitchFLOAT (−90 to 90, default 0) — Vertical starting tilt (0 = horizon, negative = floor, positive = sky).
z_offsetFLOAT (−99 to 99, default 0) — Camera height on the vertical axis as % of sphere radius.
🧭 Quick Usage Guide
  1. Add Panorama 360 Viewer Eternal (search 360 or look in ⚡ ETERNAL ● ↩ /🌐 360).
  2. Connect any 2:1 equirectangular image into image (and optionally continue from its image output).
  3. Queue the workflow — the sphere renders live inside the node.
  4. Drag to orbit, scroll to zoom, toggle Auto to drift, or open Settings to adjust camera height, exposure, zoom limits, drag speed, and the equatorial horizon guide.

Ported from pavel-zinchenko/comfyui-360-viewer (MIT) and expanded in-house with V3 schema support (UI.PreviewImage, zero manual temp files), pass-through output, batch frame_index, FOV write-back, quick sliders, fullscreen glass HUD, and the Gear Settings panel.

No extra Python packages are required for the 360 viewer (trimesh in pyproject.toml is only imported by the 3D mesh nodes).
